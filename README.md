Bioinformatics Analyst focused on **cancer genomics, multi-omics, computational biology, and precision oncology**.

## Current Works

- Precision oncology and translational genomics
- Multi-omics integration
- Somatic variant and copy-number analysis
- Epigenomics and tumor immune profiling
- Single-cell genomics
- Statistical genomics and survival analysis
- Interpretable machine learning for biomedical data
